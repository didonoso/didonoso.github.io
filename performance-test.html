📊 Run Lighthouse

Open Chrome DevTools and run Lighthouse audit:

  1. Press F12 to open DevTools
  2. Go to "Lighthouse" tab
  3. Select "Performance" only
  4. Choose "Desktop" or "Mobile"
  5. Click "Analyze page load"

Expected Score: 95-100
